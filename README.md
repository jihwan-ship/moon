# 롤랑 대 짬타이거

Library of Ruina(Project Moon)를 바탕으로 만든 비공식 팬게임입니다. 검은 침묵 롤랑이 부대 짬통을 지키는 짬타이거를 상대로 원작식 합 전투를 벌입니다.

## 실행

설치할 것 없이 `index.html`을 브라우저로 열면 됩니다.

## 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 스타일 |
| `src/data.js` | 책장, 주사위, 내성, 계급(페이즈), 대사 데이터. 수치 조정은 여기서 |
| `src/art.js` | 임시 그래픽(무기 실루엣, 캐릭터, 주사위 아이콘) SVG |
| `src/game.js` | 속도 주사위, 합 판정, 장면 진행, 연출 |

데이터를 로직과 분리해 두었기 때문에, 나중에 라오루 모드(카드 XML)로 옮길 때 `src/data.js`를 기준으로 변환하면 됩니다.

## 규칙 요약

- 장면마다 롤랑 머리 위에 속도 주사위가 뜹니다. 주사위에 전투 책장을 놓고 짬타이거 주사위를 대상으로 정합니다.
- 서로 상대 주사위를 노리거나 롤랑 주사위가 더 빠르면 합, 아니면 일방 공격입니다. 속도가 높은 순서로 처리합니다.
- 공격끼리는 높은 쪽이 피해를 줍니다. 방어가 이기면 차이만큼 흐트러짐 피해를 돌려주고, 회피가 이기면 흐트러짐을 회복하고 주사위를 다시 씁니다.
- 흐트러짐이 0이 되면 다음 장면 동안 행동하지 못하고 받는 피해가 2배가 됩니다.
- 롤랑은 원작 검은침묵의 책장(체력 106, 흐트러짐 56, 속도 2~7, 타격 견딤)을 씁니다. 아홉 공방 책장을 모두 쓰면 Furioso가 손에 들어옵니다.
- 책장 이름과 비용은 원작 기준이고, 주사위 수치는 임시값입니다.

## 짬타이거 기믹

| 계급 | 추가 기믹 |
|---|---|
| 이병 | 짬밥 섭취: 이 카드에 피해를 주지 못하면 장면 끝에 체력 20% 회복 |
| 일병 | K2 점사: 탄약 3 소모. 탄약이 떨어지면 탄약 보급(주사위 없음)으로 빈틈 |
| 상병 | 군기 잡기, 주사위 3개 |
| 병장 | 얼차려: 엎드려뻗쳐(다음 장면 속도 주사위 -1), 오리걸음(다음 장면 회피 불가) |

## 리소스

현재 그림은 모두 직접 그린 임시 SVG입니다. 원작 게임 파일에서 추출한 일러스트나 음악은 공개 배포본에 넣지 않습니다.
